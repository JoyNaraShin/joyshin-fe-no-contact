# 연락처 제외 포트폴리오

이메일·전화번호·GitHub·LinkedIn 및 원본 사이트 링크를 제외한 독립 배포본입니다.
프로토타입 링크는 유지합니다.

사이트: https://joynarashin.github.io/joyshin-fe-no-contact/

## 소스와 배포

`joyshin-fe-no-contact.zip`에 수정된 전체 소스, 의존성 잠금 파일, 빌드 결과가 포함되어 있습니다.
GitHub Actions는 압축을 풀고 소스의 타입·린트 검사 및 빌드를 수행한 후 GitHub Pages에 배포합니다.
원본 포트폴리오 저장소는 변경하지 않습니다.

수정할 때는 압축을 풀어 `joyshin-fe-no-contact` 폴더에서 작업한 다음 같은 구조로 압축하여 업로드합니다.
